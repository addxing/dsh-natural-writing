# 自然文风 · 去 AI 味

这是安装在 DeepSeek Harness 当前 profile 的 Host 插件，不是 Harmony 应用功能。无需编译或额外 API Key，不改业务代码。

## 使用

启用后，后续模型步骤收到自然文风要求，覆盖聊天回复、新写或改写的邮件、文案、报告和 Office 文档正文。文件处理仍使用 Harness 已有工具和对应 Office 技能；本插件不是 Word 格式解析器，也不会扫描或批量覆盖已有文档。

可直接说：

- “写一份项目周报，语气自然，少用套话。”
- “润色这段内容，保留事实和数据，直接给正文。”
- “把这个 Word 文档的正文写得更自然，保留标题、表格和引用，另存副本。”
- “检查这段文字中空泛、模板化的表达。”

模型可使用只读工具 `natural_writing_review`。结果包含命中表达、行号、列号、字符范围、邻近上下文和局部建议。默认最多 12 条，可设置 1–30 条；正文最多 60000 个 UTF-16 代码单元（大部分中文字符占一个，部分 emoji 占两个），超出需分段。

默认保护引号内文字。如果引号只是强调或标示口号，可以说：“检查引号内的文案，设置 `reviewQuotedText: true`，只提建议，不修改原文引用。”Markdown 块引用仍受保护。

行号和列号从 1 开始，列号按 Unicode 字符计数；`start`、`end` 是原文中的 UTF-16 零起点范围，结束位置不含在内，可用 `text.slice(start, end)` 取出命中。工具仅检查少量常见中文表达，不会自动润色、不输出 AI 概率、不增加外部网络请求。

## 软件开发场景

默认优先准确、可执行、可验证，而不是追求个性或口语化：

- 需求文档保留主体、触发条件、输入输出、权限、边界、异常和验收标准；必须、应、可以、不得的约束强度不变。
- 测试用例保留编号、需求关联、前置条件、数据、步骤和可观察预期；不能把预期结果写成实际执行结果，不凭空宣称通过。
- 开发与测试报告区分完成、进行中、待验证、未执行和计划，写清依据、阻塞与下一步。
- 统一术语，不为避免重复而改换业务名称；保护接口、字段、枚举、状态码、路径、版本、优先级、比较符号和单位。
- 原文没有定义的业务规则、阈值、性能指标、测试数据和结果不能补造，缺失或矛盾单列待确认。仅润色不等于完整需求评审或测试设计。
- 必要的标题、列表、表格、编号和重复术语不是缺陷，不为去 AI 味删除。

可说：“润色这份需求文档，保持约束强度和术语一致；缺失信息只列待确认，不补造功能。”或“优化测试用例的表达，预期结果必须可观察；没有需求依据的细节不要猜测。”

这些规则是生成提示词，不是强制语义校验器。`natural_writing_review` 不检查需求完整性、用例覆盖率或测试结果真伪，仍只筛查少量中文表达。

## 写作原则

直接进入内容、减少模板开头和收尾、用具体动作替代空泛修饰、避免机械列表和重复总结。按场景保持正式或日常语气，不一律口语化。

保留事实、数字、日期、单位、专业术语、限定条件、否定和不确定性，不杜撰亲历、案例或来源。代码、公式、引用及要求逐字保留的内容不做默认改写。用户明确的格式和文体要求优先。

## 边界

这是生成阶段的文风引导，不是强制过滤器。模型可能不完全遵循，不承诺每篇都达到同样效果，更不保证通过任何 AI 检测。检查工具保护常见围栏代码、缩进代码、多反引号代码、公式、链接目标、链接定义和显式块引用；可见链接标签仍参与检查。

保护逻辑只是 Markdown/LaTeX 的常见语法子集，不是完整解析器。单引号与双引号默认保护，启用引号检查时不再保护引号内容；明确要求逐字保留的字符串仍需模型遵守。裸 URL 以中文句读为边界，引用链接的标识不参与检查。美元金额与内联公式有歧义，数字开头且没有 LaTeX 命令或明显运算标记的候选按金额处理；复杂公式建议使用 `\\(...\\)`、`\\[...\\]` 或代码围栏保护。四空格或制表符缩进按代码保护，纯文本的缩进段落也可能被跳过；畸形、嵌套语法仍需人工核对。无关键词命中不代表整体文风自然，不能替代上下文阅读。没有新增批量文档解析和自动改写流程，真实 Office 文件的端到端处理与排版仍未验证。

全局提示词段落对使用常规系统提示词组装的 agent 生效。使用独立外部运行时、完全替换系统提示词的 preset、独立翻译服务等不保证接收该段落。已有回复和文件不会追溯改变。

## 管理

在 Harness 插件管理中查找“自然文风 · 去 AI 味”或包名 `@local/dsh-natural-writing`，可以禁用或移除。安装影响当前 profile 的所有会话，并在重启后保留。本地安装关联此源码目录，请保留目录；修改已安装的 JavaScript 后需重启 Harness 才能加载新版本。

## 实现与验证

使用公开的 `systemPrompt.section` 注册独立段落，使用 `tools.register` 提供只读检查，注册都归插件 effect 生命周期所有。卸载时移除段落和工具，不接管流、不重写日志、不拦截文件写入。

执行 `node --test test/*.test.js` 运行验证，执行 `node --check index.js` 和 `node --check policy.js` 做语法检查，均不进行编译。

图标为本插件原创 SVG，随包提供；中英文显示元数据在 locale 目录中。
